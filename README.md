В данном проекте представлен фреймворк для автотестов максимально приближенный к продуктовому, на примере рандомного тестируемого сайта. Это один из нескольких проектов, где отображается возможность использовать автотестирование с разными возможными комбинациями библиотек.

1. API тесты с использованием requests + pytest
2. UI тесты с использованием selenium + pytest, с разделением на браузеры и устройства (десктоп браузер и мобильный браузер) на базе POM.
3. Allure отчетность
